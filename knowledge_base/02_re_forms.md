# งานบริการการศึกษา แบบฟอร์มคำร้อง และงานทะเบียน มทร.อีสาน วิทยาเขตขอนแก่น

## ระบบบริการการศึกษาออนไลน์ (ESS)
- **ระบบ ESS (Education Student Service):** https://ess-register.rmuti.ac.th/AppKK/
- **เข้าสู่ระบบ:** https://ess-register.rmuti.ac.th/AppKK/auth/login
- **บริการในระบบ:** ลงทะเบียนเรียนออนไลน์, ตรวจสอบตารางเรียน-ตารางสอบ, ตรวจสอบผลการเรียน (Grade), ตรวจสอบสถานะการเงิน/ค่าธรรมเนียมการศึกษา, ยื่นคำร้องขอเพิ่ม-ถอนรายวิชาในระยะเวลาที่กำหนด

## รายการแบบฟอร์มคำร้องสำคัญ (Request Forms)
ดาวน์โหลดแบบฟอร์มได้ที่เว็บไซต์วิทยาเขต https://web.kkc.rmuti.ac.th/p/download หรือติดต่อแผนกงานวิชาการและงานทะเบียน:
1. **คำร้องทั่วไป (General Request - R.01):** ใช้สำหรับแจ้งความประสงค์หรือยื่นคำร้องในเรื่องที่ไม่มีแบบฟอร์มเฉพาะ
2. **คำร้องขอลาพักการศึกษา / รักษาสถานภาพนักศึกษา (R.04):**
   - ใช้เมื่อมีความจำเป็นต้องหยุดพักการเรียนชั่วคราว (เช่น ปัญหาสุขภาพ, ภารกิจส่วนตัว)
   - ต้องชำระค่าธรรมเนียมรักษาสถานภาพนักศึกษาตามระเบียบ
3. **คำร้องขอลาออกจากการเป็นนักศึกษา (R.05):**
   - ยื่นต่ออาจารย์ที่ปรึกษา หัวหน้าสาขาวิชา และคณบดี พร้อมแนบสำเนาบัตรประชาชน
4. **คำร้องขอคืนสภาพการเป็นนักศึกษา (R.07):**
   - ใช้กรณีพ้นสภาพเนื่องจากขาดการลงทะเบียนหรือไม่ได้รักษาสถานภาพในระยะเวลาที่กำหนด
5. **คำร้องขอลงทะเบียนเรียนเทียบรายวิชา / ข้ามสถาบัน (R.11):**
   - ใช้เมื่อต้องการลงทะเบียนเรียนวิชาในหลักสูตรอื่นหรือสถาบันอื่นเพื่อนำมาเทียบเคียง
6. **คำร้องขอเพิ่ม-ถอนรายวิชาล่าช้า (Late Add/Drop - R.14):**
   - ใช้กรณีเกินกำหนดเวลาเพิ่ม-ถอนในระบบ ESS
   - ต้องได้รับความยินยอมและลงลายมือชื่อจากอาจารย์ผู้สอน, อาจารย์ที่ปรึกษา และหัวหน้าสาขาวิชา
7. **คำร้องขอเปิดรายวิชา / ขอเพิ่มจำนวนที่นั่ง (Quota Extension - R.16):**
   - ใช้กรณีกลุ่มเรียนเต็ม หรือต้องการให้สาขาวิชาเปิดหมู่เรียนพิเศษ
8. **คำร้องขอเทียบโอนผลการเรียน (Credit Transfer - R.26):**
   - สำหรับนักศึกษาที่จบ ปวส. หรือย้ายโอนมาจากสถาบันอื่น นำผลการเรียนเดิมมาเทียบโอนหน่วยกิต
9. **คำร้องขอเอกสารทางการศึกษา (R.30):**
   - ใบรับรองสภาพการเป็นนักศึกษา, ใบรายงานผลการศึกษา (Transcript) ทั้งภาษาไทยและภาษาอังกฤษ

## ขั้นตอนการยื่นคำร้องและการติดตามผล
1. **ดาวน์โหลดและกรอกข้อมูล:** กรอกรายละเอียดในแบบฟอร์มให้ครบถ้วน ถูกต้อง ชัดเจน
2. **เสนอลงนาม:** นำเสนออาจารย์ที่ปรึกษา -> หัวหน้าสาขาวิชาวิศวกรรมคอมพิวเตอร์ -> คณบดีคณะวิศวกรรมศาสตร์ ตามลำดับ
3. **ยื่นเอกสาร:** ส่งที่แผนกงานบริการการศึกษา/งานทะเบียน คณะวิศวกรรมศาสตร์ มทร.อีสาน วิทยาเขตขอนแก่น
4. **การตรวจสอบผล:** ใช้เวลาดำเนินการประมาณ 3-5 วันทำการ สามารถตรวจสอบสถานะการอนุมัติได้ผ่านระบบ ESS หรือติดต่อเจ้าหน้าที่งานทะเบียน
